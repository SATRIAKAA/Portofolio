Machine Learning · Natural Language Processing

Sentiment Analysis — Review Classification

A Streamlit application for analyzing review sentiment. Upload a CSV dataset, choose its text and sentiment columns, then compare Linear SVM, Multinomial Naive Bayes, and ordinal Linear Regression for binary or three-class classification. The app validates and cleans the data, reports model evaluation metrics, and predicts sentiment for new text.
